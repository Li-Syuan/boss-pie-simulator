# 老闆，餅不夠分了！

**[直接開始遊戲](https://li-syuan.github.io/boss-pie-simulator/)**

六位有記性的員工、十二個工作日，以及一位覺得披薩可以解決所有問題的老闆。

原創漫畫風的職場經營小遊戲。繁體中文，支援桌機滑鼠與手機觸控，不需登入、下載或外部服務。

## 怎麼玩

在月底前完成 72 點主專案、守住現金，也讓員工願意留下。每個工作日最多 20 秒；點選管理決策會提前結算一天。正常計時一局約 4 分鐘，提早操作可以更快完成。

- 八種決策：承諾獎金、披薩、開會、現金獎金、半天假、急單、設備升級、全力衝刺。
- 每位員工都有自己的信任、疲勞、個性與吐槽。點選角色可以查看。
- 承諾隔天到期，必須選擇付清 32 或跳票。重複跳票會失去更多信任。
- 工作產出帶來現金，每日在職人員產生人事成本。信任、疲勞與設備影響效率。
- 急單優先使用產出，三天內交完收 52，逾期扣 25。不要只看收入忘記主專案。
- 信任低於 18 或疲勞達 95 會先警告；連續兩個工作日處於危險狀態就離職。
- 披薩吃多效果遞減，低信任時還會反彈；連續開會也會讓人疲勞。

## 五種結局

全員離職的「全公司只剩你」、現金耗盡的「夢想很大，帳戶很小」、完成主專案且信任至少 65 的「大家真的有分到」、完成專案但信任不足的「有賺錢，沒朋友」，以及其餘的「月底勉強存活」。

結算可回看三個轉折，收集「披薩暴君」「會議永動機」「說到做到」「急單馴獸師」等稱號，並下載戰績圖片。未到期承諾與未結急單會列在結算，不能算作已兌現或已交付。

## 暫停與存檔

預設靜音，按音效按鈕後才啟用低音量音效。玩法與員工資訊視窗會停止計時，切換分頁也會自動暫停，回來後手動繼續。

當前局、聲音設定與已收集結局只存在瀏覽器本機。重新開啟可接續，離線期間不推進。無法使用本機儲存時仍可玩，但關閉後不保留。不同裝置不會同步。

## 本機開啟

下載專案後，直接在 Chrome 或 Edge 開啟 `index.html`，不需要安裝套件或建置。

`engine.js` 負責經營規則，`scene.js` 負責原創漫畫繪圖，`app.js` 負責操作與存檔。一般模式提供唯讀 `bossView()`；`?qa=1` 才提供 `bossQA.advance(seconds)` 測試時間推進，測試仍遵守決策與承諾規則，沒有直接指定結局的入口。

所有公司、人物、財務數值與事件均為架空創作。願景不可兌換現金。
